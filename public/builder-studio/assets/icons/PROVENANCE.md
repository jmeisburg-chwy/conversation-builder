# Builder control icon provenance

The SVG files in this directory are the unmodified outline assets from
[Tabler Icons v3.35.0](https://github.com/tabler/tabler-icons/tree/v3.35.0/icons/outline):
`arrow-up`, `arrow-down`, `copy`, `trash`, `chevron-down`, `plus`, `pencil`,
`archive`, `minus`, `letter-t`, `user`, `dog`, `shield-check`, and
`square-check`.
